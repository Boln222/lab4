# Лабораторная работа №4. Ансамбли и полносвязные нейронные сети

Цель — решить задачу классификации из предыдущей работы с помощью ансамбля или
полносвязной нейронной сети, осмысленно подобрать параметры и сравнить метрики.

Исходный notebook оставлен для экспериментов. Сдаваемая контрактная функция
находится в `ensemble_models.py`. Не меняйте `grader_contracts`, название
функции, её обязательный первый параметр и аннотацию возврата.

## Контрактная функция

Реализуйте `run_ensemble_experiment`. Она получает train/test split в
`EnsembleInput`, обучает выбранную модель только на train-части и возвращает:

- читаемое `model_name`;
- вероятности положительного класса и бинарные предсказания на test;
- ROC-AUC, accuracy, precision, recall и F1, вычисленные на test.

Можно использовать Random Forest, Extra Trees, AdaBoost, Gradient Boosting,
HistGradientBoosting, Voting/Stacking или полносвязную `MLPClassifier`.
Разрешены собственные признаки и предобработка, но нельзя использовать
`test_target` для fit, feature selection или подбора гиперпараметров.

На `german.csv` выполните несколько осмысленных экспериментов. Для ROC-AUC
используйте вероятности, а не бинарные предсказания. Ограничьте вычисления так,
чтобы один запуск был воспроизводим и укладывался в разумное время на CPU.

## Обязательный отчёт `REPORT.md`

В корне репозитория добавьте `REPORT.md` с разделами:

1. `## Данные и подготовка` — split, признаки, пропуски, масштабирование и
   другие преобразования;
2. `## Гипотезы и эксперименты` — какие модели и параметры проверялись, почему;
3. `## Метрики` — таблица экспериментов с ROC-AUC, accuracy, precision, recall,
   F1 и выбранным критерием выбора;
4. `## Выбранная модель` — что выбрано и почему именно она;
5. `## Выводы и ограничения` — что улучшило/ухудшило результат, какие есть
   ограничения;
6. `## Воспроизводимость` — random seed, split и способ повторить запуск.

Нужен именно ход исследования, а не только финальная метрика. LLM-рецензент
прочитает отчёт и очищенный код, затем при необходимости задаст вопросы только
про ансамбли или архитектуру, которые действительно использованы в решении.
